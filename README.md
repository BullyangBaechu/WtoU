# Project Arrow

## 📌 개요  
‘Arrow’는 Unreal Engine 기반의 TPS 슈터 프로토타입 프로젝트로, 클라이언트 플레이에 초점을 맞춰 캐릭터 조작, 카메라 시스템, 탄도/Projectile, AI 행동·추적 시스템 등을 구현하였습니다. 향후 MMO/MMORPG로 확장 가능한 구조를 설계하는 것을 목표로 합니다.

## 🛠️ 기술 스택  
- Unreal Engine 5.x  
- C++17  
- Behavior Tree 기반 AI 시스템  
- 데이터 기반 무기/탄도 파라미터 설계  
- 컴포넌트 기반 객체 구조 구현
